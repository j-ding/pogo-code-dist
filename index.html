Check a meetup from your phone

A bookmarklet is a bookmark that runs a small script on the page you're on. Tap it on a Campfire meetup to see who checked in, then send the list here.

  1. Tap Copy bookmarklet below. Check the box shows text starting with javascript:.
  2. Bookmark any page, then edit that bookmark: name it cfcheck and replace its address with what you copied.
  3. Test it: on any page (not Campfire), run cfcheck. A message saying to open a Campfire meetup means it works.
  4. Open a meetup on campfire.scopely.com in the same browser, logged in, and run cfcheck.
  5. Tap Send to PoGo Code Dist to save the meetup here. Sending the same meetup again replaces the old copy.

Running it: in Safari, open Bookmarks and tap cfcheck. In Chrome, tap the address bar, type cfcheck, and tap the bookmark in the suggestions (tapping it in the bookmarks list doesn't run it).

When you run it, a PoGo Code Dist tab opens for a moment to hand Campfire the latest script, then closes. If Chrome blocks that tab, allow pop-ups for campfire.scopely.com. It always shows something when it runs: the check-in panel, a message, or an error.

Google Apps Script Setup

  1. Create a new Google Sheet
  2. Go to Extensions > Apps Script
  3. Replace the code with the script from google-apps-script.js
  4. Click Deploy > New deployment
  5. Select Web app, set access to "Anyone"
  6. Copy the deployment URL into js/site-config.js
  7. In Project Settings > Script properties, add ADMIN_USERNAME and ADMIN_PASSWORD

Event alerts (optional, free)

  1. Make a free account at onesignal.com and create an app. Choose Web, then Custom Code
  2. Site URL: https://j-ding.github.io. Leave the service worker settings blank; the site sets them
  3. In OneSignal's Settings > Keys & IDs, copy the App ID and create an API key
  4. In Apps Script Script properties, add ONESIGNAL_APP_ID and ONESIGNAL_API_KEY
