Google Apps Script Setup

  1. Create a new Google Sheet
  2. Go to Extensions > Apps Script
  3. Replace the code with the script from google-apps-script.js
  4. Click Deploy > New deployment
  5. Select Web app, set access to "Anyone"
  6. Copy the deployment URL into js/site-config.js
  7. In Project Settings > Script properties, add ADMIN_USERNAME and ADMIN_PASSWORD
